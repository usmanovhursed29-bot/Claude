# Анализ Корана: идеи для роликов

Программа читает весь Коран (114 сур, 6236 аятов, 603 отрывка) и по каждому отрывку предлагает до 3 идей для коротких роликов: хук, что сказано в аяте, что пишут классические тафсиры, как применить сегодня, научный факт с оценкой надёжности, риск и пометку «показать знающему человеку».

## Команды
```bash
npm run estimate                 # отрывки и примерная цена, без запросов
node run.mjs count النحل         # точный подсчёт слова по арабскому тексту (без ИИ)
node run.mjs count благодар ru   # по русскому переводу
node run.mjs sample 14:7 3       # пробный разбор 3 отрывков (нужен ключ API)
node run.mjs batch 1-114         # весь Коран пакетом со скидкой 50% (нужен ключ API)
node run.mjs collect             # забрать результаты пакета → out/report.md
```

## Правила, зашитые в задание ИИ
- Только данный текст; хадисы и другие аяты по памяти не приводятся.
- Тафсир только общеизвестный, с уровнем уверенности; иначе «проверить».
- Наука: «установлено / спорно / натяжка», без «Коран доказал».
- Числа считает код (`count`), не ИИ.
- Спорное отмечается для проверки знающим человеком.

## Данные
Пакет quran-json 3.1.2 (CC-BY-SA 4.0): арабский текст quranenc.com, перевод смыслов Э. Кулиева (tanzil.net), транскрипция tanzil.net. ⚠️ Права на перевод Кулиева у правообладателя: в роликах короткие цитаты с указанием автора.

Пример результата: `out/demo-report.md` (2 отрывка, разобраны вручную по тем же правилам).
