# Идея для ролика из Корана

Каждый запрос — одна новая сура и одна готовая идея ролика. Тему не берём из готовых подборок: находим её сами при чтении всей суры.

## Шаги
1. `cd quran-insights && node run.mjs pick` — программа выбирает случайную ещё не разобранную суру и кладёт весь её текст в `out/surah-<N>.md`. Если владелец назвал суру, передай её номер: `node run.mjs pick 16`.
2. Прочитай файл суры целиком. Для очень длинной суры читай частями, но всю.
3. Выпиши 3–5 кандидатов-тем из разных частей суры, выбери одну самую сильную для ролика.
4. Числа, на которые опирается идея, посчитай программой: `node run.mjs count <слово> [ar|ru|en]`. Сам числа не придумывай.
5. Научные факты проверь веб-поиском и дай ссылки. Если подтверждения нет — так и скажи.
6. Выдай идею в формате ниже, сохрани её в `out/ideas-history.md` (дописать в конец) и отметь суру: `node run.mjs done <N> "<тема>"`. Закоммить и запушь.

## Запрещённые темы
- Судный день, конец света, знамения конца времён, «карта того света», рай и ад как основная тема ролика. Если сура в основном об этом, найди другую тему в ней или возьми следующую суру.
- Фетвы и юридические решения.

## Правила честности
- Только текст суры; хадисы и другие аяты по памяти не приводить.
- Тафсир — только общеизвестное мнение классиков с уровнем уверенности, иначе «проверить по тафсиру».
- Не писать «Коран доказал» научную теорию. Оценка связи: установлено / спорно / натяжка.
- Без медицинских обещаний.
- Спорное по вероубеждению — пометка «показать знающему человеку».

## Формат ответа владельцу
**Сура N «Название» — тема одной строкой**
- Почему эта сура и эта тема (что нашёл при чтении, 2–3 предложения)
- Аят(ы): арабский текст + перевод смыслов Кулиева с номером
- Хук (первые 3 секунды)
- Сценарий ролика 45–60 с: 5–7 коротких блоков
- Наука: факт + источник + оценка связи
- Как применить сегодня
- Риски и что проверить перед публикацией
- Другие темы из этой суры на будущее (2–3 строки)
