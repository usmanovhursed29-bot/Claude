# Сайт-портфолио Kwantoww (kwantoww.pages.dev)

- `index.html` — главная с первым экраном «деньги клиента»: где теряются деньги → что чиню → когда окупится, калькулятор окупаемости (сайт 5 000 ₽ / средний чек).
- `index.before-2026-11-27.html` — прежняя главная (для отката).
- `_worker.js` — то, что сейчас выложено: отдаёт новую главную, а все остальные страницы и картинки берёт из прежней выкладки `https://ba0f6c68.kwantoww.pages.dev`.

Почему так: загрузка файлов в Cloudflare Pages из облачной среды Claude не проходит (прокси подменяет ключ загрузки), поэтому выкладка идёт одним файлом `_worker.js` через API деплоя.
Откат: Cloudflare → Workers & Pages → kwantoww → Deployments → `ba0f6c68` → Rollback.
