# Сайт Javob по полкам WordPress

| Полка WordPress | У нас | Статус |
|---|---|---|
| Записи / Страницы | `content/pages.js`, все тексты в одном месте | На месте |
| Главная | `pages[0]`, тип `landing` | На месте |
| Медиафайлы | пока нет картинок | Нет |
| Внешний вид → Тема | `src/template.js`, один шаблон | На месте |
| Внешний вид → Меню | `nav()` в шаблоне | В коде |
| Плагины → Заголовки и бренд | `src/brand.js` | На месте |
| Плагины → Карта сайта и robots | строятся из `pages.js` в `src/worker.js` | На месте |
| Плагины → Редиректы | `src/redirects.js` | На месте |
| Плагины → Аналитика | `brand.analyticsToken` (Cloudflare Web Analytics) | Ждёт токена |
| Пользователи | клиенты бота: `../bot/src/tenants/` | На месте |
| Настройки → Постоянные ссылки | без слэша на конце, `/x/` → `/x` (301) | На месте |

Новый тип страницы делается полем `type` в `pages.js`, а не новым файлом в коде.
Проверка: `node test/run.mjs` (эти же правила потом проверяет ночной сторож).
