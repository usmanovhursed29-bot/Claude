# Бот чайханы «Мадина» (пилот Javob)

Telegram-бот: меню, адреса двух точек, часы и телефон, бронь стола (уведомление владельцу), передача живому человеку. На свободные вопросы отвечает ИИ (Workers AI) строго по данным из `src/data.js`; если ответа нет, говорит «не знаю».

## Как поменять цены, меню, адреса
1. Открой `src/data.js`.
2. Поменяй цифры в `price`, названия блюд, часы, телефон.
3. Когда цены настоящие, поставь `demoPrices: false`: пропадёт подпись «Цены примерные».
4. Выложи заново (`npx wrangler deploy`).

## Проверка локально
```bash
node --experimental-sqlite test/run.mjs
```

## Что нужно для запуска
- Токен бота от @BotFather → `nekurs/env.master` как `MADINA_BOT_TOKEN` (не в чат).
- Токен Cloudflare API → `nekurs/env.master` как `CLOUDFLARE_API_TOKEN`.
- Chat ID отца или администратора для броней.

## Почему Cloudflare работает для гостей из России
Гости общаются с ботом через Telegram, а серверы Telegram сами обращаются к Worker. Ограничение загрузки сайтов на Cloudflare в России к этому пути, по нашей логике, не относится. ⚠️ Проверим на реальном запуске.
