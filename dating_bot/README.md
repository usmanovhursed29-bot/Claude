# Бот знакомств для Telegram

## Что умеет

- **Анкета:** имя, возраст, пол, кого ищешь, город, описание, фото.
- **🔍 Смотреть анкеты** — лента: ❤️ лайк, 💌 лайк с сообщением, 👎 дальше, ⚠️ жалоба. После каждого действия сразу следующая анкета.
- **💘 Кто меня лайкнул** — анкеты тех, кто тебя лайкнул, с их сообщением. Можно ответить взаимностью.
- **Взаимная симпатия** — оба получают анкету и контакт друг друга.
- **👤 Моя анкета** — заполнить заново, сменить фото/текст, скрыть анкету.
- **⭐ Подписка** (оплата звёздами Telegram):
  - безлимит лайков (бесплатно — 25 в день) и сообщений (бесплатно — 3 в день);
  - анкета показывается чаще, лайки — первыми;
  - фильтры: только мой город, возраст;
  - ↩️ вернуть пропущенную анкету;
  - значок ⭐ в анкете.
- **💬 Общий чат** — кнопка-ссылка на твою группу.
- **Безопасность:** с 14 лет; подростки (14–17) видят только сверстников ±2 года, взрослые — только взрослых. Жалобы приходят админу с кнопкой «Забанить».
- **Админ-команды:** `/stats`, `/unban <id>`, `/refund <id> <charge_id>`.

## Запуск

1. В Telegram открой **@BotFather** → `/newbot` → получи токен.
2. Узнай свой ID в **@userinfobot**.
3. Создай группу для общего чата → «Пригласить по ссылке» → скопируй ссылку.
4. Установи Python 3.10+ и выполни:

```bash
cd dating_bot
pip install -r requirements.txt
cp .env.example .env
```

5. Открой `.env` и впиши `BOT_TOKEN`, `ADMIN_ID`, `CHAT_LINK`.
6. Запусти:

```bash
python bot.py
```

Бот работает, пока запущена программа. Чтобы он работал 24/7, его нужно запустить на сервере (VPS).

## Цены подписки

Меняются в `bot.py`, словарь `PLANS`: `код: (дней, звёзд)`.
Звёзды, полученные ботом, можно вывести через @BotFather (Fragment).
