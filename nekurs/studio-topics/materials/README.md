# Материалы «Studio: Темы»

Прочитай до первой цели. Правила Пульта и дома Studio лежат в материалах «Старта» (`nekurs/studio-start/materials/README.md`) и действуют и здесь: пиши в ленту перед каждым заметным шагом, результаты показывай через `pult result`.

## Что лежит
- `data/niches.json.gz` — карта ниш, 0,65 МБ, 1 069 ниш Рунета. По каждой нише:
  - цифры;
  - небольшие сайты, которые уже побеждают;
  - до 60 главных запросов.

  Ниши 18+ и казино в карту не попали.
- `tools/topics.py` — инструмент части: карта, ниша, свежие запросы, таблица тем. Все команды: `topics.py -h`.
- `tools/bukvarix_fetch.py` — полная база Букварикса на 2 млрд запросов: 18 ГБ архива, нужно 60 ГБ места. Только если ученик сам хочет и компьютер тянет (это видно по `check_pc.py` из «Старта»). Для тем она не нужна.
- `test_*.py` — проверки для робота клуба. Ученику не нужны.

## Запуск
Из рабочей папки:

```
uv run --no-project --python 3.12 nekurs/studio-topics/materials/tools/topics.py <команда>
```

Дальше в тексте пишем просто `topics.py`. Таблицы инструмент кладёт в дом Studio:
- `<дом>/out/topics/` — то, что видит ученик;
- `<дом>/data/topics/` — сырые запросы.

## Что значат цифры
Объясняй ученику своими словами, примерно так:
- **Спрос в месяц** — сколько раз в месяц ищут запросы ниши в Яндексе. Считается точная частота, запросы от 500 в месяц.
- **Вопросы** — какая доля главных длинных запросов задана вопросом: как, что, почему, сколько, что лучше. Вопрос — это готовый хук.
- **Деньги** — доля спроса со словами «купить», «цена», «заказать», «услуги». Если деньги есть, есть и что продавать.
- **Гиганты** — сколько выдачи держат 211 самых больших сайтов Рунета: маркетплейсы, справочники, крупные СМИ. Чем меньше, тем свободнее.
- **Малым сайтам** — примерно сколько переходов в месяц достаётся небольшим сайтам. Это место для маленького автора.
- **Совпадений** — сколько запросов ниши содержат слова ученика. Столбец появляется только при поиске по словам. 1–2 совпадения — обычно случайность.

По умолчанию таблица отсортирована «для роликов»: наверху ниши, где много вопросов или покупок и мало гигантов. Другие сортировки:
- `--sort demand` — спрос;
- `--sort money` — денежный спрос;
- `--sort questions` — спрос на вопросы;
- `--sort free` — переходы небольшим сайтам.

## Свежие запросы
- Команда `topics.py fetch <слово> [<слово> ...] --niche <id>` спрашивает API Букварикса (`https://api.bukvarix.com`, ключ `free`). Он возвращает все запросы, где есть эти слова, с частотами.
- Затравку бери короткую: «брекеты», а не «сколько стоят брекеты в москве».
- API бесплатный и общий для всех. Не дёргай его в цикле: несколько слов за раз. Между словами инструмент сам ждёт секунду.
- Если инструмент пишет «это потолок --max», подними `--max`.
- Если API не отвечает или не пускает, скажи об этом ученику. Тогда темы строй по запросам из карты: `topics.py niche <id>`.

## Таблица тем
- Тема — это вопрос или задача людей, записанные их словами.
- Спрос темы — сумма точных частот её запросов из файла `niche-<id>.tsv`. Её считаешь ты.
- Столбцы `тема;спрос;запросы;формат`, разделитель `;`, кодировка UTF-8. Формат — одно из: ответ на вопрос, сравнение, ошибки, цена, история.
- `topics.py sheet <файл> --pult` проверяет таблицу, дописывает строку источника и показывает таблицу в Пульте.

## Источник данных
Каждая таблица заканчивается строкой `# Данные: Букварикс (bukvarix.com)`. Это условие Букварикса.
- Не удаляй эту строку и не выдавай данные за свои.
- Таблицы нужны для роликов ученика. Перепродавать их как сервис подбора слов нельзя.
